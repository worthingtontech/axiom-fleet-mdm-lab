# AXIOM — brand assets

The identity for Project AXIOM. Direction **"Enclave"**: three nested hexagons are
the three **trust tiers**; the solid gold core is the **High-Trust Enclave** — the
weights-adjacent thing every other control exists to protect. Cool steel
infrastructure, one warm guarded center.

| Asset | File | Use |
|---|---|---|
| Primary mark | [`axiom-mark.svg`](axiom-mark.svg) | full color, README/site, any size |
| Mono mark | [`axiom-mark-mono.svg`](axiom-mark-mono.svg) | favicons, badges, single-ink contexts (inherits `currentColor`) |

## Palette

| Token | Hex | Role |
|---|---|---|
| Slate Ink | `#0D1420` | ground |
| Steel | `#7E91AC` | tier structure (outer hexagon) |
| Signal Teal | `#1FB9A9` / `#20C4B3` | fleet · live telemetry · verified (middle hexagon) |
| Enclave Gold | `#EAB53E` | the protected core (inner hexagon) — used sparingly |

## Type voice

Grotesque display for the wordmark (`AXIOM`, wide tracking); **monospace** for
eyebrows, taglines, and data — it reads "engineering lab," which is the point.

## Rules

- Keep gold for the **core only**. It signifies the enclave; don't spend it elsewhere.
- Minimum clear space around the mark ≈ the width of one outer-hexagon edge.
- The mono mark is the favicon; keep it stable so browser tabs stay recognizable.
